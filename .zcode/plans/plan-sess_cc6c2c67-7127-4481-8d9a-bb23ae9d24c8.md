## XY Pad 灰度渐变背景方案

只改一个文件：`plugins/BandPass/src/controls/FilterNodePad.h` 的 `DrawTrack()`（两个 pad 共用此绘制，自动同时生效）。

### 视觉设计

去掉现在的整块 COL_BLOCK 填充和所有白色分隔线，改为按频率网格逐块填充灰色。色块边界沿用现有分隔频率（m×10^n ∈ [20, 20000]），共 27 块：

| 组 | 频率范围 | 块数 | 灰度走向（0=黑 255=白） |
|---|---|---|---|
| G1 | 20–100 Hz（20/30/…/100） | 8 | 204 → 225（步进 3） |
| G2 | 100–1000 Hz | 9 | 211 → 231 |
| G3 | 1000–10000 Hz | 9 | 218 → 238 |
| G4 | 10000–20000 Hz | 1 | 228 |

满足你提出的全部关系：
- 每组内部由深变浅（左深右浅）；
- G2 起点 211：比 G1 末端 225 深、比 G1 起点 204 浅；
- G3 起点 218：比 G2 末端 231 深、比 G2 起点 211 浅；
- G4 单块 228：比 G3 末端 238 深、比 G3 起点 218 浅；
- 所有值都在 204–238 之间，整体偏浅（现 pad 底色为 232，最深 204 与控制点的深色圆 56 对比度依然很高；控制点外环 232 在偏深色块上反而更清晰）。

### 实现

```cpp
void DrawTrack(IGraphics& g) override
{
  const IRECT tb = PlotRect();
  const IParam* pf = GetParam(0);
  auto xOf = [&](double f) { return tb.L + (float) pf->ToNormalized(f) * tb.W(); };

  struct Band { double lo, hi; float v0, v1; };
  static const Band kBands[] = {
    { 20.,    100.,   204.f, 225.f },
    { 100.,   1000.,  211.f, 231.f },
    { 1000.,  10000., 218.f, 238.f },
    { 10000., 20000., 228.f, 228.f },
  };

  for (const Band& band : kBands)
  {
    // 收集组内边界频率（升序），含组首尾
    double edges[16]; int n = 0;
    edges[n++] = band.lo;
    for (int decade = 1; decade <= 10000; decade *= 10)
      for (int m = 1; m <= 9; ++m)
      {
        const double f = m * decade;
        if (f > band.lo && f < band.hi) edges[n++] = f;
      }
    edges[n++] = band.hi;

    float xs[16];
    for (int i = 0; i < n; ++i) xs[i] = xOf(edges[i]);

    const int cells = n - 1;
    for (int i = 0; i < cells; ++i)
    {
      const float t = (cells > 1) ? (float) i / (cells - 1) : 0.f;
      const int v = (int) std::lround(band.v0 + (band.v1 - band.v0) * t);
      g.FillRect(IColor(255, v, v, v), IRECT(xs[i], tb.T, xs[i + 1], tb.B));
    }
  }
}
```

要点：
- 组间共享边界（100、1000、10000 Hz）由相同公式计算，浮点值一致，相邻色块无缝；20/20000 恰好是参数范围两端，ToNormalized 得 0/1，精确贴住 pad 左右边缘；
- 白色网格线（`g.DrawLine(COL_BG, …)` 循环）全部删除；
- 每帧 27 次 FillRect，性能无影响。

### 验证
构建 APP/AU/VST3 通过后即完成（按你之前的要求，不截图验证）。

如果具体灰度值（204–238 这个区间、组间错位量 7）你想调深/调浅，实施后只需改 `kBands` 四行数字即可。
